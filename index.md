`git commit -m` is a Git command used to save a snapshot of staged changes with a message describing the changes. The `-m` stands for message. For example, `git commit -m "Add calculator"` saves the staged changes with the message "Add calculator" in your local Git history. To upload the commit to GitHub, use `git push`.
